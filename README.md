# Invoice Manager

## Project Overview

Invoice Manager is a personal web application that helps users organize invoices, find them when needed, and track product warranties.

## Main Features

* User registration, login, and profile management.

* Personal store management.

* Add invoices by uploading PDF files, uploading images, or entering invoice details manually.

* View, edit, delete, search, and filter invoices.

* Generate and scan QR codes for invoices.

* Manage warranties and track their expiration status.

## Technologies Used

* **Backend:** PHP

* **Database:** SQLite

* **Frontend:** HTML, Tailwind CSS, JavaScript

* **QR Code Generation:** qrcode.js

* **QR Code Scanning:** html5-qrcode

* **Development Environment:** XAMPP

* **Version Control:** Git and GitHub
